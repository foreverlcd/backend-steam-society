# F2: verificación de correo y 2FA (ADR-024)

- **Repo:** ambos
- **Dificultad:** alta (planificador). Zona roja: auth.
- **Rama:** feat/f2-identity (backend y web)

## Objetivo
Confirmar el correo con un enlace y añadir verificación en dos pasos con app (TOTP): obligatoria para admin, opcional para el resto.

## Contexto mínimo
- docs/07-DECISIONS.md (ADR-024), docs/03-DATA-MODEL.md, docs/FLOWS.md §9–10
- Backend: src/modules/auth/*, src/shared/http/account-policy.decorators.ts, src/config/env.ts, prisma/migrations/20261117150930_add_email_verification_and_mfa
- Web: src/lib/api/{auth,mfa,types,errors}.ts, src/lib/auth/auth-context.tsx, src/components/auth/*, src/components/account/security-view.tsx, src/app/verify-email, src/app/(app)/account/security, src/app/(app)/admin/layout.tsx

## Criterio de terminado
- [x] Registro envía enlace; el token se guarda como hash, sirve una vez, expira (48 h); reenviar invalida el anterior.
- [x] Sin correo confirmado: 403 `EMAIL_NOT_VERIFIED` al reservar y al enviar el perfil a revisión.
- [x] TOTP RFC 6238 sin dependencias nuevas; secreto cifrado AES-256-GCM; sin reutilizar un código (paso de tiempo); 10 códigos de recuperación de un solo uso (hash).
- [x] Login en dos pasos (`pendingMfa`, 5 min); límite de intentos por cuenta.
- [x] Admin sin 2FA: 403 `MFA_ENROLLMENT_REQUIRED` salvo rutas `@AllowWithoutMfa`; no puede desactivarla.
- [x] Web: paso de código o código de recuperación en el login, página `/verify-email` (confirma con un clic, no al abrir), aviso con "Reenviar enlace", página Seguridad, admin redirigido a activar.
- [x] Tests: unit + e2e backend (296 / 70), tests web; gate full verde; probado en navegador con ui-shots y el correo real de Mailpit.
- [x] Seeds: admin nace verificado; seed-demo verifica correos y aprueba mentoras por BD con auditoría.

## Fuera de alcance
- Separar admin en roles (superadmin, finanzas, soporte, moderación), WebAuthn/passkeys: aplazados (ADR-024). SMS descartado.
- QR en la pantalla de activación: requiere una dependencia (preguntar antes). Hoy: enlace `otpauth://` + clave en grupos de 4.
- Recuperación si se pierden teléfono y códigos: hoy es manual (soporte, por BD). Pendiente de decidir.
