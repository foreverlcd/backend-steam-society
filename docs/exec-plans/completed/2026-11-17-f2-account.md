# F2: cuenta (sesiones, cambios de contraseña y correo, datos personales)

- **Repo:** backend (web en una rama aparte)
- **Dificultad:** alta (planificador). Zona roja: auth y eliminación de datos.
- **Rama:** feat/f2-account

## Objetivo
Que cada persona vea y cierre sus sesiones, cambie contraseña y correo de forma segura, descargue sus datos y elimine su cuenta.

- docs/discovery/08-ROADMAP-V3.md (F2), docs/07-DECISIONS.md (DA-04, P-03), docs/03-DATA-MODEL.md

## Criterio de terminado
- [x] Sesiones: listar (id público = hash), cerrar una, cerrar las demás; cambiar contraseña y activar 2FA cierran las demás.
- [x] Step-up: contraseña + código 2FA si la cuenta lo tiene.
- [x] Cambio de correo con enlace al correo nuevo, aviso al actual y al anterior al confirmar; carrera "correo tomado" → 409.
- [x] HIBP opcional y que no bloquea si falla.
- [x] Exportar: JSON con una sección por módulo; sin datos de terceros.
- [x] Eliminar: confirmación `ELIMINAR`, step-up, 409 con reservas abiertas, 403 admin; anonimiza en una transacción; cierra todas las sesiones; la mentora sale del catálogo.
- [x] Tests unitarios y e2e; `E2E_DATABASE_NAME=steam_society_test_f2b scripts/gate.sh full` verde.
